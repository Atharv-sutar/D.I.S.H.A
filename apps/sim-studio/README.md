# D.I.S.H.A. Simulator Studio (`apps/sim-studio/`, Port `3002`)

Behind-the-scenes demonstration control room for **M. Chinnaswamy Stadium**:
- Select any stadium zone/gate/stand/concession directly on the 3D hologram.
- Inject or clear crowd congestion spikes (`50%–99%`) in real time.
- Trigger unusual activity & operational incidents (`queue_surge`, `crowd_bottleneck`, `medical`, `security`, `facility_fault`) with live 3D beacons.
- Switch match-day event phases or trigger curated 1-click scenarios (`Gate 1 Rush`, `Halftime Concession Spike`, `Medical Emergency`, `Post-Match Egress`, `Reset`).
