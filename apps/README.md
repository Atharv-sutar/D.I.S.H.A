# D.I.S.H.A. Frontend Applications (`apps/`)

**Owner**: [@Ankit-Navi-8294](https://github.com/Ankit-Navi-8294)

## Applications

1. **[`ops-dashboard/`](ops-dashboard/)** (Port `3000`) — Stadium Operations Command Center:
   - Real-time stadium zone & gate congestion heatmap
   - Entry & concession queue telemetry monitor
   - Emerging incident feed with acknowledge/dispatch/resolve actions
2. **[`fan-app/`](fan-app/)** (Port `3001`) — Fan Experience & Smart Navigation App:
   - First-time visitor stadium wayfinding
   - Live recommendations for least-crowded gates, concessions, and restrooms
   - Step-by-step accessible navigation & live event advisories
3. **[`shared/`](shared/)** — Shared TypeScript contract definitions (`shared/types/contracts.ts`) aligned to [`contracts/schemas/`](../contracts/schemas/).
