# Fan Experience & Smart Navigation App (`apps/fan-app/`)

**Owner**: [@Ankit-Navi-8294](https://github.com/Ankit-Navi-8294)

## Scope

- First-time visitor stadium map & step-by-step accessible wayfinding
- Live least-crowded gate & shortest total-time (walk + wait) concession suggestions
- Real-time stadium advisories via `WS /ws/fan`

## Recommended Setup (Next.js / React + TypeScript)

```bash
cd apps/fan-app
npm install
npm run dev
```
