# Stadium Operations Command Center (`apps/ops-dashboard/`)

**Owner**: [@Ankit-Navi-8294](https://github.com/Ankit-Navi-8294)

## Scope

- Live multi-zone stadium congestion heatmap
- Gate & concession queue length / wait-time monitors
- Real-time incident alert stream (`WS /ws/ops`) and dispatch workflow (`PATCH /api/v1/incidents/{id}`)

## Recommended Setup (Next.js / React + TypeScript)

```bash
cd apps/ops-dashboard
npm install
npm run dev
```
